IPTV Viewer — NEWLINE network (VLC)
====================================

Приложение для просмотра IPTV с тёмным современным интерфейсом,
оригинальным логотипом NEWLINE network и движком VLC.

Источники плейлистов (выбираются в настройках):
  1. IPTVPortal — https://newline.iptvportal.ru/
  2. ISP-NL     — http://tv.isp-nl.ru/nltv.m3u

Как запустить (портативная версия):
  1. Распакуйте архив IPTVViewer_Newline_VLC.zip в любую папку.
  2. Запустите IPTVViewer.exe.
  3. Папку libvlc НЕ удаляйте и не переносите — это движок VLC,
     он должен лежать рядом с IPTVViewer.exe.

Требования:
  - Windows 7 SP1 и новее (64-битная или 32-битная).
  - .NET Framework 4.8 (на Windows 10/11 уже установлен;
    на Windows 7 при необходимости установите с сайта Microsoft).

Настройки:
  %LOCALAPPDATA%\IPTVViewer\settings.json
  Пример: C:\Users\<Имя>\AppData\Local\IPTVViewer\settings.json
  Сохраняются: выбранный источник, URL плейлистов, автозагрузка,
  режим внешнего проигрывателя, положение и размер окна.

Возможности:
  - Заставка с оригинальным логотипом NEWLINE network.
  - Тёмная тема интерфейса.
  - Поиск каналов по названию и группе.
  - Воспроизведение через VLC (LibVLCSharp): HLS/m3u8, HTTP-потоки и т.д.
  - Регулировка громкости.
  - Двойной клик по каналу или кнопка «Воспроизвести».
  - Кнопка «Внешний плеер» — открыть поток во внешней программе.
  - Настройки в LocalAppData (стандартные параметры создаются автоматически).

Примечание:
  Первый источник (newline.iptvportal.ru) — это веб-портал, который может
  требовать авторизацию. Второй источник (tv.isp-nl.ru/nltv.m3u) — готовый
  m3u-плейлист и работает сразу. URL обоих источников можно изменить
  в окне «Настройки».
