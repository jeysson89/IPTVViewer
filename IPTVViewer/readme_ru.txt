IPTV Newline - NEWLINE network (VLC)
====================================

Приложение для просмотра IPTV скандинавской и светлой темы —
интерфейс в стиле NEWLINE network на движке VLC.

Источники каналов (две кнопки в шапке):
  1. IPTVPORTAL - https://newline.iptvportal.ru/
  2. M3U (ISP)  - http://tv.isp-nl.ru/nltv.m3u

Как установить:
  Вариант 1 (один файл): запустите IPTVViewer.exe — движок VLC вшит
    внутрь и распаковывается при первом запуске (несколько секунд).
  Вариант 2 (портативно): распакуйте архив в любую папку
    и запустите IPTVViewer.exe.

Требования:
  - Windows 7 SP1 и новее (64-битная или 32-битная).
  - Ничего устанавливать НЕ нужно: все компоненты, включая
    платформу .NET и движок VLC, уже вшиты в один файл
    IPTVViewer.exe.

Настройки:
  %LOCALAPPDATA%\IPTVViewer\settings.json
  пример: C:\Users\<Имя>\AppData\Local\IPTVViewer\settings.json

Возможности:
  - Два источника каналов с быстрым переключением.
  - Поиск по каналам, телепрограмма (EPG).
  - Полноэкранный режим (двойной клик по видео).
  - Громкость колёсиком мыши над видео.
  - Кнопка «Поверх всех окон».
  - Автообновление в один клик прямо из плеера.

Обновление вручную:
  IPTVViewer.exe --check-updates
