IPTV Viewer — NEWLINE network (VLC)
====================================

Приложение для просмотра IPTV с тёмной и светлой темами интерфейса,
оригинальным логотипом NEWLINE network и движком VLC.

Источники плейлистов (кнопки IPTVPORTAL и IPTV в главном окне):
  1. IPTVPortal — https://newline.iptvportal.ru/
  2. ISP-NL     — http://tv.isp-nl.ru/nltv.m3u

Как запустить (портативная версия):
  1. Распакуйте архив IPTVViewer_Newline_VLC.zip в любую папку.
  2. Запустите IPTVViewer.exe.
  3. Папку libvlc НЕ удаляйте и не переносите — это движок VLC,
     он должен лежать рядом с IPTVViewer.exe.

Требования:
  - Windows 7 SP1 и новее (64-битная или 32-битная).
  - .NET Framework 4.8 (на Windows 10/11 уже установлен;
    на Windows 7 при необходимости установите с сайта Microsoft).

Настройки:
  %LOCALAPPDATA%\IPTVViewer\settings.json
  Пример: C:\Users\<Имя>\AppData\Local\IPTVViewer\settings.json
  Сохраняются: выбранный источник, URL плейлистов, автозагрузка,
  режим внешнего проигрывателя, телепрограмма (EPG), светлая тема,
  автопроверка обновлений, положение и размер окна.

Возможности:
  - Заставка с оригинальным логотипом NEWLINE network.
  - Тёмная и светлая темы (переключаются в настройках без перезапуска).
  - Кнопки источников IPTVPORTAL и IPTV — переключение и загрузка плейлиста
    одним кликом.
  - Список каналов справа, поиск по названию и группе.
  - Воспроизведение через VLC (LibVLCSharp): HLS/m3u8, HTTP-потоки и т.д.
  - Полный экран: F11 или двойной клик по видео, выход — Esc.
    В полноэкранном режиме список каналов появляется справа при движении
    мыши и скрывается в простое.
  - Телепрограмма (EPG):
      * Загрузка по ссылке url-tvg из плейлиста, кэширование на диск
        (повторные запуски — мгновенно).
      * Текущая передача показывается в списке каналов при наведении
        и на выбранном канале.
      * Правый клик по каналу — полная телепрограмма с подсветкой
        передачи «сейчас в эфире» и кнопкой «Смотреть канал».
  - Регулировка громкости.
  - Двойной клик по каналу или кнопка «Воспроизвести».
  - Режим «внешний проигрыватель» включается в настройках.
  - Настройки в LocalAppData (стандартные параметры создаются автоматически).
  - Автоматическая проверка обновлений (GitHub Releases) при запуске;
    ручная проверка — «Настройки» -> «Проверить обновления».

Управление:
  - F11           — полноэкранный режим.
  - Esc           — выход из полноэкранного режима.
  - Двойной клик  — по каналу: воспроизведение; по видео: полный экран.
  - Enter         — воспроизвести выбранный канал.
  - ПКМ по каналу — телепрограмма канала.
  - Ctrl+F        — переход в поле поиска.

Примечание:
  Первый источник (newline.iptvportal.ru) — это веб-портал, который может
  требовать авторизацию. Второй источник (tv.isp-nl.ru/nltv.m3u) — готовый
  m3u-плейлист и работает сразу. URL обоих источников можно изменить
  в окне «Настройки».
