Портативный IPTV-плеер для Windows с движком VLC.

## Что нового в v0.0.18
- Заставка с логотипом на области видео, когда воспроизведение остановлено.
- Защита от двух запущенных копий: второй запуск открывает уже работающее окно и предупреждает, что запуск двух плееров невозможен.
- Исправлено: при переключении каналов логотип больше не появляется поверх видео.
- Надёжная фоновая загрузка логотипов каналов (без зависаний и гонок кэша).

## Установка
Скачайте и запустите однофайловый IPTVViewer.exe — устанавливать ничего не нужно.

## Обновление
Плеер сам предложит обновление при запуске и заменит себя новой версией.
Проверить вручную: IPTVViewer.exe --check-updates
